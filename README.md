# FTD Website

**Fei Tian Dancers at Berkeley Website**

Live site: [https://ftdancers.vercel.app/](https://ftdancers.vercel.app/)

This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).  
It serves as the official website for Fei Tian Dancers at UC Berkeley, featuring upcoming events, galleries, member dashboards, and more.

---

## Getting Started

### 1. Clone the repository
```
git clone https://github.com/<your-username>/ftd-website.git
cd ftd-website
```
### 2. Install dependencies
```
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```
### 3. Run the development server
```
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
---
## Tech Stack
- Framework: Next.js (React + TypeScript)
- Database & Auth: Supabase
- Image Hosting: Cloudinary
- Deployment: Vercel
- Styling: Tailwind CSS, Framer Motion (animations)
- UI Design: Figma
  
## Features
- Interactive event and gallery pages
- Member and board dashboards (Supabase role-based access)
- Cloudinary-integrated image carousels
- Responsive navbar and modern UI/UX
- Deployed on Vercel for performance and reliability
